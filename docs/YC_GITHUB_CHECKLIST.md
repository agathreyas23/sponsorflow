# YC and GitHub Checklist

Use this before sharing SponsorFlow with YC, internships, or technical reviewers.

## Product Story

- What problem does it solve?
- Who uses it?
- What does the user do first?
- What output does the user get?
- Why is this better than spreadsheets and generic email templates?

## Repo Checklist

- Public repository exists
- README has a live demo link
- README explains the problem and the product
- Setup instructions work
- No secrets are committed
- `.env.example` is present
- Production build passes with `npm run build`

## Demo Checklist

- Landing page loads
- Sponsor discovery flow works in demo mode
- Email generation flow works in demo mode
- Dashboard pages load
- Personal `/aditi` page has polished photos and links

## Profile Checklist

- GitHub profile photo matches professional materials
- Bio mentions Purdue, Economics & Industrial Engineering, and SponsorFlow
- LinkedIn is linked
- SponsorFlow repo is pinned
- Portfolio or live demo link is visible
